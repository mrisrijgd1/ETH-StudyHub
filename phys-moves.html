From lesson 1

Check the units

How it works: After every result, and to check a formula you half remember: both sides must have the same unit. A wrong unit is a wrong formula, found in ten seconds.

Seen in: lesson 1, example 3, lesson 4, example 4, lesson 5, example 3, lesson 9, example 1, lesson 12, example 3, lesson 14, example 1

Choose axes, split into components

How it works: Put the origin where the motion starts and one axis along the motion (along a ramp, along the rope). Then every vector equation becomes one equation per component, and each one is easy.

Seen in: lesson 1, example 2, lesson 2, example 1, lesson 3, example 3, lesson 3, example 4, lesson 5, example 1

Integrate, then fix the constants

How it works: From the acceleration to the velocity to the position: integrate, and fix each constant with an initial condition ($x(0)$, $v(0)$). For $m\dot v=F(v)$, separate the variables first.

Seen in: lesson 1, example 2, lesson 2, example 4, lesson 3, example 5, lesson 4, example 2, lesson 12, example 1

On a circle: $v=\omega R$ and $v^2/R$ to the centre

How it works: Whatever moves on a circle (a carousel, a loop, an orbit) needs the net force $m\frac{v^2}R$ towards the centre. Write it as one equation along the radius; tangential changes of speed are a separate equation.

Seen in: lesson 1, example 3, lesson 4, example 3, lesson 6, example 2, lesson 9, example 1

From lesson 2

Free-body diagram, one body at a time

How it works: Draw one body and only the forces acting on it: weight, normal force, rope, spring, friction. Never put a force on the body that it exerts on something else.

Seen in: lesson 2, example 2, lesson 3, example 1, lesson 3, example 2, lesson 3, example 3, lesson 3, example 4, lesson 4, example 1, lesson 4, example 3, lesson 6, example 3, lesson 10, example 2, lesson 10, example 3, lesson 11, example 2, lesson 11, example 3

Second law per component

How it works: $m a_x=\sum F_x$, $m a_y=\sum F_y$, with the axes chosen above. Equilibrium is the special case $a=0$.

Seen in: lesson 2, example 4, lesson 3, example 2, lesson 3, example 4, lesson 3, example 5, lesson 5, example 3, lesson 11, example 2

Third-law pairs act on different bodies

How it works: The force of $A$ on $B$ and of $B$ on $A$ are equal and opposite, but they act on different bodies, so they never cancel in one free-body diagram.

Seen in: lesson 2, example 2, lesson 3, example 1

Impulse is the change of momentum

How it works: $\Delta\vec p=\int\vec F\,dt$. For a short hit (a ball on a wall, a collision) you don't need the force, only the momenta before and after.

Seen in: lesson 2, example 1, lesson 8, example 3

Balance over a small time $dt$

How it works: When the mass changes (a rocket), write the momentum at $t$ and at $t+dt$, keep the terms of first order in $dt$, and divide by $dt$.

Seen in: lesson 2, example 3

Momentum is conserved

How it works: No external force in a direction (or a hit so short that external forces don't matter): the total momentum in that direction is the same before and after. One equation per component.

Seen in: lesson 2, example 3, lesson 8, example 1, lesson 8, example 2, lesson 8, example 3

From lesson 4

In an accelerated frame, add the fictitious forces

How it works: In the frame of the sledge or the carousel, add $-m\vec A$, the centrifugal force and the Coriolis force to the real forces; then use the second law as usual.

Seen in: lesson 4, example 1, lesson 4, example 2, lesson 4, example 3, lesson 4, example 4

From lesson 5

Work integral along the path

How it works: $W=\int\vec F\cdot d\vec r$: write $d\vec r$ along the path (piece by piece), take the dot product, integrate. A force perpendicular to the motion does no work.

Seen in: lesson 5, example 1, lesson 5, example 2

Energy with friction: $T_1+U_1+W_{\text{fr}}=T_2+U_2$

How it works: Friction does negative work $W_{\text{fr}}=-F_Rs$. Put it into the energy balance instead of solving the equation of motion.

Seen in: lesson 5, example 4, lesson 6, example 3

From lesson 6

Energy conservation between two points

How it works: Only conservative forces do work: $T_1+U_1=T_2+U_2$. Choose the two points well (start and the point asked about) and the zero of $U$ once.

Seen in: lesson 6, example 2, lesson 8, example 1, lesson 8, example 2, lesson 9, example 2

Conservative? Test the curl, then integrate

How it works: Compute $\nabla\times\vec F$. If it is zero, find $U$ with $\vec F=-\nabla U$ by integrating one component and fixing the rest.

Seen in: lesson 6, example 1

From lesson 7

Angular momentum: $\vec L=\vec r\times\vec p$, conserved without torque

How it works: For a central force (gravity, a string through a hole) the torque about the centre is zero, so $L=mrv_\perp$ stays constant.

Seen in: lesson 7, example 1

Use the centre of mass

How it works: $\vec r_S=\frac1M\sum m_i\vec r_i$ (or $\int\vec r\,dm$). It moves as if all the mass and all external forces sat there; in its own frame the total momentum is zero.

Seen in: lesson 7, example 2, lesson 8, example 3, lesson 10, example 1

From lesson 8

Check a limiting case

How it works: Set a mass to zero, make two masses equal, let an angle go to $0$ or $90^\circ$. The result must do what you expect there (for equal masses in a central elastic collision, the first ball stops).

Seen in: lesson 8, example 1

From lesson 9

Only the mass inside counts

How it works: Shell theorem: outside a sphere, all its mass acts from the centre; inside a homogeneous shell, the field is zero. So at radius $r$ inside the earth only the mass within $r$ pulls.

Seen in: lesson 9, example 3

Small oscillations: bring it to $\ddot x+\omega^2x=0$

How it works: Write the equation of motion, use $\sin\varphi\approx\varphi$ for small angles, and read off $\omega^2$ as the factor in front of $x$ (or $\varphi$).

Seen in: lesson 9, example 3, lesson 12, example 2, lesson 13, example 3

From lesson 10

Statics: forces and torques balance

How it works: $\sum\vec F=0$ and $\sum\vec M=0$. Take torques about the point where the unknown forces act: they drop out of that equation.

Seen in: lesson 10, example 2, lesson 10, example 3

From lesson 11

Moment of inertia: slice, integrate, Steiner

How it works: $J=\int r_\perp^2\,dm$ with thin slices or shells; for a parallel axis, $J_A=J_S+Md^2$, always passing through the centre of mass.

Seen in: lesson 11, example 1, lesson 12, example 2

Rolling and rope constraints

How it works: Rolling without slipping: $v=\omega R$, $a=R\ddot\varphi$. A rope that doesn't slip ties the body's $a$ to the wheel's $\ddot\varphi$. These extra equations close the system.

Seen in: lesson 11, example 2, lesson 11, example 3

From lesson 12

Ansatz, then fit the constants

How it works: For $\ddot x+2\rho\dot x+\omega_0^2x=\dots$ insert $A\cos(\omega t+\delta)$ (or $e^{\lambda t}$), solve for $\omega$, $A$, $\delta$, and fit the free constants to the initial conditions.

Seen in: lesson 12, example 1, lesson 12, example 3, lesson 13, example 1

From lesson 13

Superpose and read off

How it works: Add two oscillations with $\cos a+\cos b=2\cos\frac{a+b}2\cos\frac{a-b}2$, or write the motion as a sum of normal modes: beats and energy exchange can be read off directly.

Seen in: lesson 13, example 2, lesson 13, example 3

From lesson 14

Ideal gas law at every corner

How it works: $pV=\nu RT$ holds in every state. With two of $p$, $V$, $T$ known at a corner, the third follows; along a known process, ratios are enough.

Seen in: lesson 14, example 1, lesson 15, example 1, lesson 15, example 3

First-law bookkeeping with the arrows

How it works: $\Delta U=Q^\swarrow+W^\swarrow$ with $\Delta U=\nu C_V\Delta T$ for an ideal gas. Find the two easy quantities for the process, then the third from the law.

Seen in: lesson 14, example 2, lesson 14, example 3, lesson 16, example 3

From lesson 15

Adiabatic: Poisson's law

How it works: No heat exchanged: $pV^\kappa$ and $TV^{\kappa-1}$ stay constant, and $W^\swarrow=\Delta U$.

Seen in: lesson 15, example 1

A cycle, step by step

How it works: Make a table: for each step $\Delta U$, $Q$ and $W$ with signs. Over the whole cycle $\Delta U=0$. Efficiency $=$ work out $/$ heat in, never more than Carnot's $1-\frac{T_2}{T_1}$.

Seen in: lesson 15, example 2, lesson 15, example 3

From lesson 16

Entropy along a reversible path

How it works: $\Delta S=\int\frac{\delta Q_{\text{rev}}}T$. For an irreversible process, compute it along any reversible path between the same two states; a bath at constant $T$ has $\Delta S=\frac QT$.

Seen in: lesson 16, example 1, lesson 16, example 2, lesson 16, example 3
