Recap of lesson 5 (5 minutes)

A subspace $W\subseteq V$: $0_V\in W$, closed under $+$, closed under scalars; then it is a vector space itself. Check yourself: is $\{(x,y,z)\in\mathbb R^3\mid x=y\}$ a subspace? Is $\{(x,y,z)\mid x=y^2\}$?

Answer

The first is: a linear condition, $0$ satisfies it, and sums and multiples keep $x-y=0$. The second is not: $(1,1,0)$ is in it but $2\cdot(1,1,0)=(2,2,0)$ has $2\ne4$. Today's question is the reverse: given some vectors, what is the smallest subspace containing them?

1. The story: the mapmakers of the Free City

The caravans of lesson 5 travel along arrows. The guild of mapmakers asks the practical question: which journeys can we describe with the roads we have? If the city has a road east and a road north, every place in the plain can be reached: go so far east, then so far north. A third road, north-east, adds nothing new; it is a mixture of the first two.

So the mapmakers look for a set of roads with two properties. Every place can be reached (the roads are enough). And no road is a mixture of the others (none is wasted). Such a set gives every place a unique address: “three east, two north”. The number of roads in it is the number of directions the land has.

In mathematics: mixtures of vectors are linear combinations, the places you can reach are the span, “no road wasted” is linear independence, a set with both properties is a basis, the address is the vector of coordinates, and the number of roads is the dimension. That the number does not depend on which basis you pick is lesson 7. Once a vector space has a basis of $n$ vectors, every vector becomes a list of $n$ numbers, and all of Linear Algebra becomes computation in $K^n$.

2. Linear combinations and the span

Throughout, $V$ is a vector space over a field $K$.

Definition (linear combination; Definition 2.2.4, p. 43). For $n\in\mathbb N$, $a_1,\dots,a_n\in K$ and $v_1,\dots,v_n\in V$, the vector $a_1v_1+\dots+a_nv_n=\sum_{i=1}^na_iv_i$ is a linear combination of $v_1,\dots,v_n$ with coefficients $a_1,\dots,a_n$. Note 2.2.5: always finitely many terms, even if you choose them from an infinite set.

Definition (span, two ways). For $S\subseteq V$:

  • (Definition 2.2.2, p. 42) $\mathrm{Sp}(S):=\bigcap\{W\mid W$ a subspace of $V$ with $S\subseteq W\}$, the smallest subspace containing $S$;
  • (Lemma 2.2.6, p. 43; the lecture's definition of the linear hull $\langle S\rangle$) the set of all linear combinations of vectors from $S$.

$\mathrm{Sp}(\emptyset)=\{0_V\}$ (Note 2.2.12: the empty sum is $0_V$). We write $\mathrm{Sp}(v_1,\dots,v_n)$ for $\mathrm{Sp}(\{v_1,\dots,v_n\})$. If $\mathrm{Sp}(S)=V$, then $S$ generates (spans) $V$, and $S$ is a generating system (Definition 2.2.10). $V$ is finite-dimensional if some finite $S$ generates it (Definition 2.2.11).

The first definition says what the span is (the smallest subspace with $S$ in it); the second says how to compute with it (write vectors as combinations). That they agree is the content of two short proofs.

Proof A: an intersection of subspaces is a subspace (Lemma 2.2.1, p. 42)

Claim. Let $(W_i)_{i\in I}$ be a nonempty family of subspaces of $V$. Then $W:=\bigcap_{i\in I}W_i$ is a subspace. In particular $\mathrm{Sp}(S)$ (Definition 2.2.2) is a subspace, it contains $S$, and it lies in every subspace that contains $S$ (Lemma 2.2.3).

The idea. Membership in an intersection is “for all $i$” (lesson 3). Each condition of the subspace test holds in every $W_i$, so it holds in the intersection.

The storyWhat you write

The places every guild's map shows. The city gate is on every map.

$0_V\in W_i$ for all $i$ (each $W_i$ is a subspace), so $0_V\in W$.

Two places on every map: their mixture is on every map too, since every map is closed under mixing.

Let $a_1,a_2\in K$, $v_1,v_2\in W$. Then $v_1,v_2\in W_i$ for all $i$, so $a_1v_1+a_2v_2\in W_i$ for all $i$, so $a_1v_1+a_2v_2\in W$.

The smallest common map: it is a map, it shows $S$, and it is inside every map that shows $S$.

$\mathrm{Sp}(S)$ is an intersection of subspaces (the family contains $V$, so it is nonempty), hence a subspace; each member contains $S$, so $S\subseteq\mathrm{Sp}(S)$; and if $W\supseteq S$ is a subspace, it is one of the intersected sets, so $\mathrm{Sp}(S)\subseteq W$. ∎

Proof B: the span is the set of all linear combinations (Lemma 2.2.6, p. 43)

Claim. For $\emptyset\ne S\subseteq V$, let $L(S)$ be the set of all linear combinations of vectors from $S$. Then $L(S)=\mathrm{Sp}(S)$.

The idea. Show $L(S)$ is a subspace containing $S$ (so $\mathrm{Sp}(S)\subseteq L(S)$, as $\mathrm{Sp}$ is the smallest), and that every subspace containing $S$ contains all combinations (so $L(S)\subseteq\mathrm{Sp}(S)$). Two inclusions, the standard way to prove a set equality (lesson 3).

What the definitions force (before any idea)
  • First line: “We show $\mathrm{Sp}(S)\subseteq L(S)$ and $L(S)\subseteq\mathrm{Sp}(S)$.”
  • For “$\subseteq L(S)$”: by Lemma 2.2.3 it suffices that $L(S)$ is a subspace with $S\subseteq L(S)$.
  • For “$L(S)\subseteq$”: any subspace $W\supseteq S$ contains every linear combination (induction on the number of terms).
The storyWhat you write

Every road is a mixture of itself: one road, coefficient one.

$S\subseteq L(S)$, since $v=1\cdot v$.

Mixing two mixtures gives a (longer) mixture.

$L(S)$ is a subspace: $0_V=0\cdot v\in L(S)$ for some $v\in S$; and if $v=\sum_{i=1}^na_iv_i$, $w=\sum_{j=1}^mb_jw_j$, then $\lambda v+\mu w$ $=\sum_i(\lambda a_i)v_i+\sum_j(\mu b_j)w_j$, a combination of $n+m$ vectors from $S$. So $\mathrm{Sp}(S)\subseteq L(S)$ (Lemma 2.2.3).

Any map that shows the roads shows every mixture: add one road at a time.

Let $W\supseteq S$ be a subspace. By induction on $n$: $a_1v_1\in W$ (LSS3); if $\sum_{i=1}^na_iv_i\in W$, then adding $a_{n+1}v_{n+1}\in W$ stays in $W$ (LSS2). So $L(S)\subseteq W$ for every such $W$, hence $L(S)\subseteq\mathrm{Sp}(S)$. ∎

  1. Rung 1. Exercise 2.2.9: show $\mathrm{Sp}(v)=\{\lambda v\mid\lambda\in K\}$. What exactly is to be shown?
    Answer

    A combination of vectors from $\{v\}$ is $a_1v+\dots+a_nv$ with all terms the same vector (finitely many terms, repetitions allowed), which equals $(a_1+\dots+a_n)v$ by V8. So every combination is of the form $\lambda v$, and conversely $\lambda v$ is a combination. “Isn't that just the definition?” Almost: the work is in collapsing repeated vectors.

  2. Rung 2. Show: if $w\in\mathrm{Sp}(v_1,\dots,v_n)$, then $\mathrm{Sp}(v_1,\dots,v_n,w)$ $=\mathrm{Sp}(v_1,\dots,v_n)$.
    Answer

    “$\supseteq$”: more vectors, more combinations. “$\subseteq$”: the right side is a subspace containing $v_1,\dots,v_n$ and $w$, so it contains the smallest such subspace, the left side. (Or: substitute $w=\sum c_iv_i$ into any combination.) This fact drives lesson 7.

  3. Rung 3. Write Proof B from the frame alone.

3. Is $w$ in the span? Solve a linear system

In $K^m$ the question “is $w$ a linear combination of $v_1,\dots,v_n$?” is a system of linear equations. Put the vectors as columns into a matrix $A=(v_1\,|\,\cdots\,|\,v_n)\in M_{m\times n}(K)$. Then $Ax=x_1v_1+\dots+x_nv_n$ (Lemma 2.2.17, p. 46), so

$$\begin{aligned}&w\in\mathrm{Sp}(v_1,\dots,v_n)\\ \iff\ &Ax=w\ \text{has a solution }x\in K^n.\end{aligned}$$

The script's example: is $(11,137)$ a combination of $v=(1,3)$ and $w=(7,73)$? Solve $x_1+7x_2=11$, $3x_1+73x_2=137$. Subtract $3\times$ the first from the second: $52x_2=104$, so $x_2=2$, $x_1=-3$. Indeed $-3\cdot(1,3)+2\cdot(7,73)=(11,137)$. In general you row-reduce $(A\,|\,w)$ (Gaussian elimination, which you know from the exercise classes).

Try it: the span of two vectors in $\mathbb R^2$

Enter $v$, $w$ and a target $t$. Move the sliders to form $\lambda v+\mu w$ (the faint grid shows integer combinations). The verdict says whether $v,w$ are independent and finds the coefficients of $t$ if they exist.

Worked example 1: all subspaces of $\mathbb R^2$ (Example 2.2.13, p. 45)

  1. Let $W\subseteq\mathbb R^2$ be a subspace with some $v\ne0$ in it. What must $W$ contain?
    Answer

    $\mathrm{Sp}(v)=\{\lambda v\}$, the line $G_v$ through $0$ and $v$ (Lemma 2.2.3: $W$ contains the smallest subspace with $v$).

  2. And if $W$ also contains some $w\notin G_v$?
    Answer

    Then $\mathrm{Sp}(v,w)=\mathbb R^2$ (Exercise 2.2.14; in coordinates: $w$ not a multiple of $v$ means $ad-bc\ne0$, and the explorer solves every $t$). So $W=\mathbb R^2$. Conclusion: the subspaces of $\mathbb R^2$ are exactly $\{0\}$, the lines through $0$, and $\mathbb R^2$ itself. In particular $\mathbb R^2=\mathrm{Sp}((1,0),(0,1))$ is finite-dimensional.

4. Linear independence

A generating system can contain superfluous vectors. Independence says: none is superfluous. The script and the lecture state it differently; both forms are needed.

Definition (script; Definitions 2.2.24 and 2.2.26, p. 48–49). A finite set $\{v_1,\dots,v_n\}\subseteq V$ (pairwise distinct) is linearly independent if

$$\begin{aligned}&\forall a_1,\dots,a_n\in K:\\ &a_1v_1+\dots+a_nv_n=0\ \Rightarrow\ a_1=\dots=a_n=0.\end{aligned}$$

An infinite set is linearly independent if every finite nonempty subset is. $\emptyset$ is independent by convention. Otherwise the set is linearly dependent: there are distinct $v_1,\dots,v_n\in S$ and $a_1,\dots,a_n$, not all $0$, with $\sum a_iv_i=0$ (Definition 2.2.32: the negation, by lesson 2).

Definition (lecture, §4). $M\subseteq V$ is linearly independent if $\forall x\in M:\ x\notin\langle M\setminus\{x\}\rangle$: no vector is a combination of the others.

In words (Note 2.2.25): $0=0v_1+\dots+0v_n$ always; independence says this trivial combination is the only way to write $0$. Examples: $\{0\}$ is dependent ($1\cdot0=0$), and so is every set containing $0$. A single $v$ is independent iff $v\ne0$ (Exercise 2.2.29, by lesson 5's rule $\lambda v=0\Rightarrow\lambda=0\vee v=0$). Two vectors are independent iff neither is a multiple of the other.

Proof C: the two definitions agree (lecture, Satz 4.0)

Claim. $M\subseteq V$ satisfies “no $x\in M$ lies in $\langle M\setminus\{x\}\rangle$” if and only if for all $n\ge1$ and distinct $x_1,\dots,x_n\in M$: $\sum_{i=1}^n\lambda_ix_i=0$ $\Rightarrow\lambda_1=\dots=\lambda_n=0$.

The idea. Both directions by contraposition (lesson 2: $\neg(A\to B)\iff A\wedge\neg B$). A nontrivial combination equal to $0$ with some $\lambda_1\ne0$ can be solved for $x_1$: divide by $\lambda_1$. Conversely, if $y$ is a combination of the others, move $y$ to the other side: coefficient $-1\ne0$.

The storyWhat you write

“$\Rightarrow$”, back door: suppose a nontrivial mixture of roads leads back to the gate. Some road is used with a nonzero amount; call it road one.

(⇒, contrapositive) Let $\sum_{i=1}^n\lambda_ix_i=0$ with some $\lambda_i\ne0$; without loss of generality $\lambda_1\ne0$ (renumber).

Then road one is a mixture of the others: walk the others, scaled, and you arrive where road one goes.

Multiply by $-\lambda_1^{-1}$: $-x_1-\sum_{i=2}^n\lambda_1^{-1}\lambda_ix_i=0$, so $x_1=\sum_{i=2}^n(-\lambda_1^{-1}\lambda_i)x_i$, which lies in $\langle M\setminus\{x_1\}\rangle$. So $M$ is not independent in the lecture's sense.

“$\Leftarrow$”, back door: if some road $y$ is a mixture of the others, go along the mixture and then back along $y$: you are at the gate, and $y$ was used with amount $-1$.

(⇐, contrapositive) Let $y\in M$ with $y=\sum_{i=1}^n\lambda_ix_i$, $x_i\in M\setminus\{y\}$ distinct. Then $0=\sum_{i=1}^n\lambda_ix_i+(-1)y$, a combination of distinct vectors of $M$ with the coefficient $-1\ne0$. ∎

The proof in one piece

(⇒) Contrapositive. If $\sum_{i=1}^n\lambda_ix_i=0$ with $\lambda_1\ne0$ (after renumbering), then $x_1=\sum_{i=2}^n(-\lambda_1^{-1}\lambda_i)x_i$ lies in $\langle M\setminus\{x_1\}\rangle$. (⇐) Contrapositive. If $y=\sum_{i=1}^n\lambda_ix_i$ with $x_i\in M\setminus\{y\}$, then $\sum_{i=1}^n\lambda_ix_i+(-1)\cdot y=0$ is a nontrivial combination. ∎

Your turn: the proof-writing ladder
  1. Rung 1. Where does the proof use that $K$ is a field?
    Answer

    In dividing by $\lambda_1\ne0$. Over a ring like $\mathbb Z$ the two notions differ: in $\mathbb Z^1$, $\{2,3\}$ has $3\cdot2-2\cdot3=0$, but $2$ is not an integer multiple of $3$.

  2. Rung 2. Negate “$\{v_1,v_2,v_3\}$ is linearly independent” in quantifiers.
    Answer

    $\exists a_1,a_2,a_3\in K:$ $a_1v_1+a_2v_2+a_3v_3=0$ $\wedge\,(a_1\ne0\vee a_2\ne0\vee a_3\ne0)$. Note “not all zero”, not “all nonzero”.

  3. Rung 3. Write Proof C from the frame: two contrapositives, “divide by $\lambda_1$” and “coefficient $-1$”.

Proof D: in a dependent list, some vector is a combination of the earlier ones (Lemma 2.3.2, p. 51; lecture, Lemma 4.2)

Claim. Let $v_1,\dots,v_m$ be linearly dependent. Then there is $j$ with (a) $v_j\in\mathrm{Sp}(v_1,\dots,v_{j-1})$ and (b) removing $v_j$ does not change the span: $\mathrm{Sp}(v_1,\dots,\widehat{v_j},\dots,v_m)$ $=\mathrm{Sp}(v_1,\dots,v_m)$.

The idea. Take a nontrivial combination equal to $0$, and let $j$ be the largest index with nonzero coefficient. Then $a_1v_1+\dots+a_jv_j=0$ with $a_j\ne0$: solve for $v_j$. It only involves earlier vectors.

The storyWhat you write

A wasteful list of roads: some nontrivial mixture returns to the gate. Look at the last road it really uses.

(a) Choose $a_1,\dots,a_m$, not all $0$, with $\sum a_iv_i=0$, and let $j:=\max\{i\mid a_i\ne0\}$. Then $a_1v_1+\dots+a_jv_j=0$ with $a_j\ne0$.

That road is a mixture of the roads before it.

$v_j=-\frac{a_1}{a_j}v_1-\dots-\frac{a_{j-1}}{a_j}v_{j-1}$ $\in\mathrm{Sp}(v_1,\dots,v_{j-1})$. (If $j=1$: $v_1=0\in\mathrm{Sp}(\emptyset)$.)

So it can be dropped from the list without losing any place.

(b) In any combination of $v_1,\dots,v_m$, replace $v_j$ by this expression: it becomes a combination without $v_j$. (Section 2, Rung 2.) ∎

Read it backwards and you get the practical test used in Serie 3, exercise 18: if no vector in a list is a combination of the earlier ones, the list is independent. Lesson 7 builds the Steinitz exchange on Proof D.

5. Bases and coordinates

Definition (basis; Definition 2.2.34, p. 50; lecture §4). $B\subseteq V$ is a basis of $V$ if (1) $B$ is linearly independent and (2) $\mathrm{Sp}(B)=V$.

Definition (dimension; lecture). If $B$ is a basis, $\dim V:=|B|$. That every basis has the same size is the main theorem of lesson 7; until then the definition is a promise.

Proof E: a basis gives unique coordinates (Proposition 2.2.35, p. 50; lecture Satz 4.1 = Serie 3, exercise 15)

Claim. $B=\{v_1,\dots,v_n\}$ is a basis of $V$ $\iff$ every $v\in V$ can be written in exactly one way as $v=a_1v_1+\dots+a_nv_n$.

The idea. Existence of a representation is “$B$ spans”. Uniqueness is independence in disguise: two representations of $v$, subtracted, give a representation of $0$; and the trivial representation of $0$ is unique exactly when $B$ is independent.

What the definitions force (before any idea)
  • “$\Rightarrow$”: existence from (2). Uniqueness: “Let $v=\sum a_iv_i=\sum b_iv_i$. … So $a_i=b_i$ for all $i$.”
  • “$\Leftarrow$”: spanning is immediate. Independence: “Let $\sum a_iv_i=0$. Since also $\sum0\cdot v_i=0$, uniqueness gives $a_i=0$.”
The storyWhat you write

Every place has an address, since the roads reach everywhere.

(⇒) Let $v\in V$. As $\mathrm{Sp}(B)=V$, $v=\sum a_iv_i$ for some $a_i$.

Two addresses for one place: walk one, then walk the other backwards. You are back at the gate.

If also $v=\sum b_iv_i$, then $0=v-v=\sum(a_i-b_i)v_i$.

No road is wasted, so the only way back to the gate is not to move: the two addresses agree.

By independence, $a_i-b_i=0$ for all $i$: the representation is unique.

Conversely, unique addresses: the gate's own address is “nowhere”, so no nontrivial mixture returns there.

(⇐) $\mathrm{Sp}(B)=V$ by existence. If $\sum a_iv_i=0=\sum0\cdot v_i$, uniqueness gives $a_i=0$ for all $i$: $B$ is independent. ∎

For an infinite basis (Serie 3, exercise 15) the same proof works with “unique up to the order of the terms, with nonzero coefficients”: a representation uses finitely many basis vectors, and you compare the two finite lists on their union. The numbers $a_1,\dots,a_n$ are the coordinates of $v$ with respect to the (ordered) basis $v_1,\dots,v_n$.

The standard bases (Example 2.2.20, p. 47).

  • $K^n$: $e_1=(1,0,\dots,0)$, …, $e_n=(0,\dots,0,1)$. Coordinates of $(a_1,\dots,a_n)$: $a_1,\dots,a_n$. So $\dim K^n=n$.
  • $K[x]_{\le n}$: $1,x,\dots,x^n$; $K[x]$: $\{x^i\mid i\ge0\}$, infinite. (Spanning: a polynomial is a finite sum $\sum a_ix^i$. Independent: a polynomial is $0$ only if all coefficients are $0$.)
  • $M_{m\times n}(K)$: the $mn$ matrices $E_{ij}$ with a single $1$ in position $(i,j)$.
  • $\mathcal P(X)$ over $\mathbb F_2$, $|X|=n$: the $n$ one-element subsets $\{x\}$.

The script asks you not to call them “canonical” (Note 2.2.21): there is nothing canonical about them.

Worked example 2: is $\{e_1,e_2,\dots\}$ a basis of the sequence space $K^\infty$? (lecture; Exercise 2.2.23, p. 48)

  1. Independent?
    Answer

    Yes: a finite combination $\sum_{i\in F}a_ie_i$ is the sequence with $a_i$ in position $i$ and $0$ elsewhere; it is $0$ only if all $a_i=0$.

  2. Spanning?
    Answer

    No: linear combinations are finite, so every vector in the span has only finitely many nonzero terms. $(1,1,1,\dots)$ is not in the span. The span is exactly the space of sequences with finite support from lesson 5. So it is not a basis. (Every vector space has a basis, but for $K^\infty$ this needs the axiom of choice, and nobody can write one down.)

Why it's cool

A basis turns any finite-dimensional vector space into $K^n$: pick a basis, and each vector is its list of coordinates. Polynomials of degree at most $3$ become lists of $4$ numbers, $2\times2$ matrices become lists of $4$ numbers, Fibonacci sequences become lists of $2$ numbers (Serie 3, exercise 17). And choosing a clever basis makes hard problems easy: in the basis $\{(1,\varphi,\varphi^2,\dots),(1,\psi,\psi^2,\dots)\}$ of the Fibonacci space, with $\varphi,\psi=\frac{1\pm\sqrt5}2$, the Fibonacci numbers have the closed formula $f_n=\frac1{\sqrt5}(\varphi^n-\psi^n)$ (Binet). Choosing the best basis is the theme of the whole second semester (eigenvectors).

For wonder: is $\mathbb R$ over $\mathbb Q$ finite-dimensional?

$\mathbb R$ is a vector space over $\mathbb Q$ (lesson 5). Is there a finite basis? No: if $b_1,\dots,b_n$ spanned, every real number would be $q_1b_1+\dots+q_nb_n$ with $q_i\in\mathbb Q$, and there are only countably many such combinations, but $\mathbb R$ is uncountable (lesson 3). So any basis of $\mathbb R$ over $\mathbb Q$ is uncountable; one exists (axiom of choice), it is called a Hamel basis, and nobody has ever seen one. A small piece of it you can see: $1,\sqrt2,\sqrt3,\sqrt6$ are independent over $\mathbb Q$ (Serie 3, exercise 19).

Worked examples: a mixed set before the exercises

Try each in your head before opening the steps.

Worked example 3: which family is a basis of $\mathbb R^3$? (FS20, question I)

(a) $(1,1,1),(1,-1,1),(-1,1,-1)$. (b) $(1,-1,0),(0,1,-1),(-1,0,1)$. (c) $(3,2,1),(4,3,2),(5,4,3)$. (d) $(1,1,0),(0,1,1),(1,0,1)$.

  1. Find a dependence in three of them.
    Answer

    (a) The third is $-1$ times the second. (b) The three vectors sum to $0$. (c) $(3,2,1)+(5,4,3)$ $=(8,6,4)=2\cdot(4,3,2)$.

  2. Check (d).
    Answer

    Independent: $a(1,1,0)+b(0,1,1)$ $+\,c(1,0,1)=0$ gives $a+c=0$, $a+b=0$, $b+c=0$; adding all three: $2(a+b+c)=0$, so $a+b+c=0$, and then $b=0$, $c=0$, $a=0$. Spanning: $(x,y,z)=a(1,1,0)$ $+\,b(0,1,1)+c(1,0,1)$ is solved by $a=\frac{x+y-z}2$, $b=\frac{y+z-x}2$, $c=\frac{x+z-y}2$. Answer (d). Note the division by $2$: over $\mathbb F_2$ the same three vectors sum to $0$ and are dependent.

Worked example 4: four true/false statements (FS17, x and xii; FS18, ix; mock HS20, (6))

  1. FS17 x: $\{(a,b),(c,d)\}\subseteq\mathbb C^2$ is a basis iff $ad-bc\ne0$.
    Answer

    True. If $ad-bc\ne0$, every $(x,y)$ has the unique solution $\lambda=\frac{xd-yc}{ad-bc}$, $\mu=\frac{ay-bx}{ad-bc}$ (the explorer's formula), so it is a basis by Proof E. If $ad-bc=0$: if $(a,b)=(0,0)$, the set contains $0$ and is dependent. Otherwise, if $a\ne0$, then $d=\frac{bc}a$ and $(c,d)=\frac ca(a,b)$; if $a=0$, then $b\ne0$ and $bc=0$ gives $c=0$, so $(c,d)=\frac db(a,b)$. Either way $(c,d)$ is a multiple of $(a,b)$: dependent (or, if equal, the set has one element and cannot span $\mathbb C^2$).

  2. FS17 xii: three vectors are independent iff they are pairwise independent.
    Answer

    False. $(1,0),(0,1),(1,1)$ in $\mathbb R^2$: any two are independent, all three are not ($(1,0)+(0,1)-(1,1)=0$). Only “$\Rightarrow$” holds (FS18 ix below).

  3. FS18 ix: if $S_1\subseteq S_2$ and $S_2$ is independent, then $S_1$ is independent.
    Answer

    True (Lemma 2.2.27): a nontrivial dependence among vectors of $S_1$ is one among vectors of $S_2$.

  4. Mock HS20 (6): $(1,i)$ and $(-i,1)$ form a basis of $\mathbb C^2$ over $\mathbb C$.
    Answer

    False: $-i\cdot(1,i)=(-i,-i^2)$ $=(-i,1)$. One is a multiple of the other ($ad-bc=1\cdot1-i\cdot(-i)$ $=1+i^2=0$). Over $\mathbb R$ the scalar $-i$ is not allowed, and the pair would be independent in $\mathbb C^2$ as a real vector space.

Worked example 5: “give the definition of a basis” (HS21, problem 3 (a), 2 points)

  1. Write what you would hand in.
    Answer

    Let $V$ be a vector space over $K$. A subset $B\subseteq V$ is a basis of $V$ if $B$ is linearly independent, i.e. for all $n\ge1$, pairwise distinct $v_1,\dots,v_n\in B$ and $a_1,\dots,a_n\in K$: $\sum a_iv_i=0$ $\Rightarrow a_1=\dots=a_n=0$, and $B$ generates $V$, i.e. every $v\in V$ is a linear combination of finitely many vectors of $B$. An ordered basis is a basis written as a list $(v_1,\dots,v_n)$, so that coordinates have an order. Both conditions, with quantifiers.

Exercises

Exercise 1 (FS17, problem 3 (a))

Let $V$ be the real vector space of polynomials of degree $\le3$. Show that $p_1=4x^3+3x^2+2x+7$, $p_2=x^3+x^2+x$, $p_3=3x^3+2x^2+x$, $p_4=9x^3+4x^2+x$ form a basis of $V$.

Hint

Only $p_1$ has a constant term. For $p_2,p_3,p_4$ compare the coefficients of $x$, $x^2$, $x^3$.

Solution

Frame: independent and spanning. Moves: compare coefficients; solve a linear system.

Independent. Let $ap_1+bp_2+cp_3+dp_4=0$. Constant term: $7a=0$, so $a=0$. Coefficients of $x$, $x^2$, $x^3$:

$$\begin{aligned}b+c+d&=0,\\ b+2c+4d&=0,\\ b+3c+9d&=0.\end{aligned}$$

Subtracting: $c+3d=0$ and $c+5d=0$, so $2d=0$, $d=0$, $c=0$, $b=0$.

Spanning. It suffices to reach $1,x,x^2,x^3$ (they span $V$). Solving the same system with right sides $e_1,e_2,e_3$:

$$\begin{aligned}x&=3p_2-\tfrac52p_3+\tfrac12p_4,\\ x^2&=-3p_2+4p_3-p_4,\\ x^3&=p_2-\tfrac32p_3+\tfrac12p_4,\end{aligned}$$

(check the $x$-, $x^2$-, $x^3$-coefficients), and $1=\frac17\big(p_1-4x^3-3x^2-2x\big)$ is then a combination too. So $\{p_1,\dots,p_4\}$ is a basis. (From lesson 7 on, “four independent vectors in a $4$-dimensional space” will be enough, and the spanning part becomes free.)

Exercise 2 (Serie 3, exercise 17: three bases of Fib)

Find three different bases of $\mathrm{Fib}$, the space of sequences $(f_n)_{n\ge0}$ with $f_{n+2}=f_{n+1}+f_n$.

Hint

A Fibonacci-type sequence is determined by $f_0$ and $f_1$. Write $F_{a,b}$ for the one starting $a,b$.

Solution

Frame: reduce to $\mathbb R^2$ via the first two terms. Moves: induction; two vectors are independent iff not multiples.

By induction, $(f_n)\in\mathrm{Fib}$ is determined by $(f_0,f_1)$, and every pair occurs. So $f=f_0F_{1,0}+f_1F_{0,1}$ for every $f\in\mathrm{Fib}$ (both sides are in $\mathrm{Fib}$ and agree in the first two terms), and the representation is unique. Hence $B_1=\{F_{1,0},F_{0,1}\}$ is a basis. Likewise $\{F_{a,b},F_{c,d}\}$ is a basis whenever $(a,b),(c,d)$ are independent in $\mathbb R^2$, i.e. $ad-bc\ne0$. Three bases: $B_1$; $B_2=\{F_{1,1},F_{2,1}\}$ $=\{(1,1,2,3,5,\dots),$ $(2,1,3,4,7,\dots)\}$; $B_3=\{(1,\varphi,\varphi^2,\dots),$ $(1,\psi,\psi^2,\dots)\}$ with $\varphi,\psi=\frac{1\pm\sqrt5}2$, which lie in Fib since $t^2=t+1$ gives $t^{n+2}=t^{n+1}+t^n$. In $B_3$: $F_{0,1}=\frac1{\sqrt5}(F_{1,\varphi}-F_{1,\psi})$, Binet's formula.

Exercise 3 (Serie 3, exercise 18 (a))

In $\mathbb Q[X]$ let $x_0=1$ and, for $n\ge1$, $x_n=1+(n+1)(X+\dots+X^n)$. Show that $\{x_n\mid n\ge0\}$ is linearly independent.

Solution

Frame: Proof D read backwards. Moves: show no vector is a combination of the earlier ones.

$\deg x_n=n$. A combination of $x_0,\dots,x_{n-1}$ has degree $\le n-1$, so $x_n\notin\mathrm{Sp}(x_0,\dots,x_{n-1})$ for every $n\ge1$. By Proof D, each finite list $x_0,\dots,x_n$ is independent (otherwise some $x_j$ would be in the span of the earlier ones). Every finite subset of $\{x_n\}$ lies in such a list, so the infinite set is independent (Definition 2.2.26 and Lemma 2.2.27).

Exercise 4 (true or false)

(a) Any two generating systems of $V$ have the same cardinality (FS17, ix). (b) Every subset of $V$ is either linearly dependent or linearly independent (FS17, xi). (c) If some $v\in V$ has exactly one representation as a combination of $v_1,\dots,v_k$, then $\{v_1,\dots,v_k\}$ is independent (mock HS20, (7)). (d) If $S$ spans $V$ and $S\subseteq T$, then $T$ spans $V$. (e) $\mathrm{Sp}(S)=S$ iff $S$ is a subspace.

Solution

(a) False: $\{e_1,e_2\}$ and $\{e_1,e_2,e_1+e_2\}$ both generate $\mathbb R^2$. (For bases it is true: lesson 7.) (b) True: “dependent” is defined as “not independent” (Definition 2.2.30). (c) True: if $\sum a_iv_i=0$ nontrivially and $v=\sum c_iv_i$, then $v=\sum(c_i+a_i)v_i$ is a second representation. (d) True: $V=\mathrm{Sp}(S)\subseteq\mathrm{Sp}(T)\subseteq V$. (e) True (for $S\ne\emptyset$; $\mathrm{Sp}(\emptyset)=\{0\}\ne\emptyset$): if $S$ is a subspace, it is the smallest one containing itself; conversely $\mathrm{Sp}(S)$ is a subspace.

Exercise 5 (Serie 3, exercise 19 (b))

Let $V\subseteq\mathbb R$ be the set of numbers $q_0+q_1\sqrt2+q_2\sqrt3+q_3\sqrt6$ with $q_i\in\mathbb Q$. Show that $\{1,\sqrt3\}$ is a basis of $V$ over the field $K_1=\mathbb Q(\sqrt2)$, but not over $K_2=\mathbb Q(\sqrt3)$.

Hint

For independence over $\mathbb Q(\sqrt2)$ you need $\sqrt3\notin\mathbb Q(\sqrt2)$. Square $\sqrt3=r+s\sqrt2$.

Solution

Frame: spanning, then independence; the field of scalars changes the answer. Moves: assume the opposite; one counterexample is enough.

Spanning over $K_1$: $q_0+q_1\sqrt2+q_2\sqrt3+q_3\sqrt6$ $=(q_0+q_1\sqrt2)\cdot1$ $+\,(q_2+q_3\sqrt2)\cdot\sqrt3$ with both coefficients in $\mathbb Q(\sqrt2)$.

Independent over $K_1$: let $a\cdot1+b\sqrt3=0$ with $a,b\in\mathbb Q(\sqrt2)$. If $b\ne0$, then $\sqrt3=-a/b\in\mathbb Q(\sqrt2)$, say $\sqrt3=r+s\sqrt2$, $r,s\in\mathbb Q$. Squaring: $3=r^2+2s^2+2rs\sqrt2$, so $rs=0$ (else $\sqrt2\in\mathbb Q$). If $s=0$: $\sqrt3=r\in\mathbb Q$, impossible. If $r=0$: $\sqrt3=s\sqrt2$, so $3=2s^2$, so $(2s)^2=6$ and $\sqrt6\in\mathbb Q$, impossible. Hence $b=0$ and then $a=0$.

Not a basis over $K_2$: $\sqrt3\in K_2$ is a scalar there, and $\sqrt3\cdot1+(-1)\cdot\sqrt3=0$ is a nontrivial dependence.
