Informatik

C++ from zero to exam level for Informatik (Fischer and Friedrich, HS26, for Mathematics and Physics), following the official lecture notes chapter by chapter. Every lesson has commented code, small coding tasks with a step-by-step method, and real exam questions with solutions.

Start here

Recommended: begin with lesson 1, in order. If you already program, still read the Task method page once: the exam is written at the computer, and the method is what gets you from an empty editor to a passing program.

Code right in the page: every coding task has an editor. Write your program, press Check, and it runs the tests, like Code Expert. Example programs have Run and Edit, so you can change them and see what happens.

A small step for a bad day: one worked example from the current lesson.

You're done when
you've finished all 14 lessons and can, without help, (1) give the type and value of any expression, (2) trace any loop or recursive function and write its output, and (3) write a short program from a task text, with the six questions, that passes the tests.
The pace
14 lessons. One lesson a day: done in 14 days. Two a day: done in 7.
Script
The official lecture notes "Introduction to Computer Science" (Fischer, Friedrich, Sasse, HS26), in English, chapters 1–18. Lessons cite them by printed page.
The exam
Written at the computer: programming tasks graded by automatic tests, plus theory questions (course organisation, lecture 0). Old paper exams (IFMP 2015–2018) are used for practice in every lesson: their question types (type and value, loop output, pre- and postconditions, number representation) are exactly the knowledge the tests check.

Lessons

  1. Lesson 1 · script ch. 1–2The Workshop of the Literal Golem

    Algorithms (Euclid), what a computer does, syntax and semantics; your first C++ program: statements, output, variables and their pitfalls, input, expressions, constants; the six questions and the trace table.

  2. Lesson 2 · script ch. 3–4Boxes of Different Shapes

    Precedence, associativity and expression trees; integer division and modulo; int, unsigned int, float, double and bool; De Morgan and short circuit; the exam's "type and value" task in five steps, with every IFMP exam 2015–2018.

  3. Lesson 3 · script ch. 5The Golem Turns Back

    if and else, for, while and do, blocks and scope, break, continue and switch; how to trace any loop and argue that it stops; every IFMP loop-output task; prime factorization and Fibonacci primes step by step.

  4. Lesson 4 · script ch. 6The Golem's Book of Spells

    Defining and calling functions, tracing a call with a new table, pass by value and the call stack, void and return; pre- and postconditions with assert, in five steps; stepwise refinement (rectangles, calendar); declarations, headers, namespaces; IFMP exam tasks on sums, inverses mod p and postconditions.

Coming next

  1. Lesson 5 · script ch. 7–8Vectors and references

    std::vector, nested vectors, pass by reference and by value, const references.

  2. Lesson 6 · script ch. 9Characters and texts

    char, ASCII, strings, the Caesar cipher.

  3. Lesson 7 · script ch. 10Recursion

    The call stack, gcd, all bit strings, recursive problem solving, recursion vs iteration.

  4. Lesson 8 · script ch. 11Number representations

    Binary and hexadecimal, signed numbers, floating point systems and IEEE 754, floating point rules.

  5. Lesson 9 · script ch. 12Custom data types

    structs, function and operator overloading.

  6. Lesson 10 · script ch. 13Information hiding

    Classes, member functions, constructors.

  7. Lesson 11 · script ch. 14Containers and iterators

    Containers, iterators, const-iterators.

  8. Lesson 12 · script ch. 15–16Pointers and linked lists

    Pointers, dynamic memory, linked lists, list iterators.

  9. Lesson 13 · script ch. 17Memory management

    A stack class, destructors, copy constructor and assignment, rule of three, shared pointers.

  10. Lesson 14 · script ch. 18Dynamic arrays

    Pointer arithmetic, an array-based vector, inserting and removing elements.
